# Полёт над Алматы

Браузерная 3D-игра: самолёт взлетает из аэропорта Алматы и облетает город и горы Заилийского Алатау.

## Как играть

Откройте `index.html` в браузере. Нужен интернет: движок Three.js загружается с CDN, а если CDN недоступен, берётся копия из `vendor/`. Если браузер не пускает локальный файл, запустите в папке проекта простой сервер:

```
python3 -m http.server 8000
```

и откройте http://localhost:8000.

### Режимы

- **Экскурсия по городу.** Пролетите через 10 золотых колец и посадите самолёт на полосу. Время записывается как рекорд.
- **Свободный полёт.** Летайте куда хотите.

### Маршрут экскурсии

1. Взлёт из аэропорта
2. Вознесенский собор (парк 28 панфиловцев)
3. Гостиница «Казахстан»
4. Площадь Республики, монумент Независимости
5. Центральный стадион
6. Esentai Tower
7. Телебашня Кок-Тобе
8. Каток «Медеу»
9. Шымбулак
10. Большое Алматинское озеро
11. Посадка в аэропорту

### Управление

| Клавиши | Действие |
|---|---|
| ↑ ↓ или W S | Нос вверх / вниз |
| ← → или A D | Крен и поворот |
| Q E | Руль направления, рулёжка на земле |
| Shift / Ctrl (или + −, R F) | Газ больше / меньше |
| C | Камера: сзади, издалека, из кабины |
| M | Звук |
| Esc или P | Пауза |

На телефоне: джойстик слева (нос и крен), полоса «ГАЗ» справа, кнопки ◀ ▶ для рулёжки.

Взлёт: дайте полный газ, после 180 км/ч поднимите нос. Посадка: сбросьте газ, плавно снижайтесь над полосой и коснитесь её не быстрее 10 м/с, затем уберите газ до остановки.

## Устройство

Вся игра в одном файле `index.html`: рельеф, улицы и дома строятся процедурно при загрузке, достопримечательности собраны из простых фигур. Высоты в игре соответствуют реальным (город около 780 м над морем, Медеу 1691 м, БАО 2511 м), а расстояния по карте сжаты примерно вдвое, чтобы маршрут проходился за несколько минут.
