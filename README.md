# Полёт над Алматы

Браузерная 3D-игра: самолёт взлетает из аэропорта Алматы и облетает город и горы Заилийского Алатау. Город построен по реальным открытым данным: около 344 тысяч зданий с настоящими контурами, улицы, железные дороги, парки, реки, озёра, канатные дороги и рельеф местности.

## Как играть

Откройте `index.html` в браузере. Движок Three.js загружается с CDN, а если CDN недоступен, берётся копия из `vendor/`. Если браузер не пускает локальный файл, запустите в папке проекта простой сервер:

```
python3 -m http.server 8000
```

и откройте http://localhost:8000.

### Режимы

- **Экскурсия по городу.** Пролетите через 10 золотых колец и посадите самолёт на полосу. Время записывается как рекорд.
- **Свободный полёт.** Летайте куда хотите.

### Маршрут экскурсии

1. Взлёт из аэропорта (полоса 23, курс на город)
2. Вознесенский собор (парк 28 панфиловцев)
3. Гостиница «Казахстан»
4. Площадь Республики, монумент Независимости
5. Центральный стадион
6. Esentai Tower
7. Телебашня Кок-Тобе
8. Каток «Медеу»
9. Шымбулак
10. Большое Алматинское озеро
11. Посадка в аэропорту

### Управление

| Клавиши | Действие |
|---|---|
| ↑ ↓ или W S | Нос вверх / вниз |
| ← → или A D | Крен и поворот |
| Q E | Руль направления, рулёжка на земле |
| Shift / Ctrl (или + −, R F) | Газ больше / меньше |
| Пробел | Форсаж в полёте |
| C | Камера: сзади, издалека, из кабины |
| M | Звук |
| Esc или P | Пауза |

На телефоне: джойстик слева (нос и крен), полоса «ГАЗ» справа, кнопка ≫ для форсажа, кнопки ◀ ▶ для рулёжки.

Взлёт: дайте полный газ, после 180 км/ч поднимите нос. Посадка: сбросьте газ, плавно снижайтесь над полосой и коснитесь её не быстрее 10 м/с, затем уберите газ до остановки.

## Устройство

- `index.html` — разметка и стили.
- `js/game.js` — игра: построение мира, физика полёта, интерфейс.
- `data/almaty-data.js` — сжатые данные карты (рельеф, здания, линии, площади).
- `tools/` — скрипты, которыми собраны данные.

Масштаб реальный: 1 единица = 1 метр, высоты над уровнем моря настоящие (аэропорт около 680 м, Медеу около 1700 м, Большое Алматинское озеро около 2510 м). Высота зданий берётся из карты, а где её нет, оценивается по типу и размеру здания.

### Как обновить данные карты

```
pip install pyarrow shapely numpy pillow
python3 tools/fetch_overture.py work/ov
python3 tools/fetch_dem.py work/dem
python3 tools/build_data.py work data/almaty-data.js
```

## Источники данных

- Здания, дороги, землепользование и вода: [Overture Maps Foundation](https://overturemaps.org/) (выпуск 2026-09-23.1), включая данные © участники [OpenStreetMap](https://www.openstreetmap.org/copyright) (ODbL) и Microsoft ML Buildings (CDLA-Permissive 2.0).
- Рельеф: [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) (SRTM и другие открытые источники).
